# Changelog

All notable changes to this project are documented in this file.

## 0.2.0

- Add support for the Bookoo Themis Ultra firmware 4.0.0 protocol.
- Correct the display-unit mapping and standby-time scaling.
- Decode powder-weight packets.
- Decode all documented automatic-mode event and settlement packets.
- Add commands for setting powder weight and shutting down the scale.
- Add automated protocol, checksum, state-update and command tests.
